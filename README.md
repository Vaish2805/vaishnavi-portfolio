# Vaishnavi Sable — Portfolio
React + TypeScript + Tailwind CSS + Framer Motion + Vite.

## Run locally
```bash
npm install
npm run dev
```

## Deploy to Vercel
1. Push this folder to a GitHub repository.
2. In Vercel, select **Add New → Project** and import the repository.
3. Framework preset: **Vite**; build command: `npm run build`; output directory: `dist`.
4. Click **Deploy**. Vercel will give you a live URL.

## Resume
Replace `public/resume.pdf` with your preferred resume. Add your verified Vercel URL to the resume header as **Portfolio**.

Project performance numbers are targets, not validated results. Update once measured.
